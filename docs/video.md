# Watching the gameplay recording

The recording opens midway through a free-running Meadowmind game. The character crosses grassland broken up by trees, berry bushes and lakes. The right-hand observation panel labels the active model “22021 pre-stim baseline.” It shows the current decision count, game time and a short log of actions. The health, satiety and hydration bars run across the top. The map and game clock continue to change between decisions.
